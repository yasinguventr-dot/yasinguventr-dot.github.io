TikTok token alma (Seç kartını)

Bu sayfadaki anahtarı, sırrı ve tokenları sohbete yapıştırma. Sadece Claude Code ortam ayarlarına gir.

1. İzin ver

TikTok'ta TARO hesabınla giriş yap ve izin ver. Tarayıcı bu sayfaya geri döner.

2. Token al

Yeni sekmede {"access_token": "...", "refresh_token": "...", "scope": "...", ...} görünür. scope içinde video.publish olmalı. Tırnak içindeki refresh_token değerini (tırnaklar hariç) kopyala. Bu değer yaklaşık 1 yıl geçerlidir.

3. Ortam ayarlarına ekle

Claude Code → Project settings → Ortam → Default yanındaki dişli. Ortam değişkenlerine ekle:

TIKTOK_CLIENT_KEY=Client key
TIKTOK_CLIENT_SECRET=Client secret
TIKTOK_REFRESH_TOKEN=2. adımdaki refresh_token

İzinli alan adlarına open.tiktokapis.com ekle ve kaydet. Sonra bu sayfayı kapat.
