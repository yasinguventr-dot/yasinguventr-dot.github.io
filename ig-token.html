Instagram token alma (Seç kartını)

Bu sayfadaki sırrı ve tokenları sohbete yapıştırma. Sadece Claude Code ortam ayarlarına gir.

1. İzin ver

Butona bas, seckartini ile giriş yap ve izin ver. Tarayıcı yasinguventr-dot.github.io/?code=... adresine döner. O sekmenin adres çubuğundaki tam adresi kopyala.

Instagram izin sayfasını aç

2. Kısa ömürlü token al

Yeni sekmede {"access_token": "...", "user_id": ..., "permissions": [...]} görünür. permissions içinde instagram_business_content_publish olmalı. Tırnak içindeki access_token değerini (tırnaklar hariç) kopyala.

3. Uzun ömürlü (~60 gün) token al

Yeni sekmede {"access_token": "...", "token_type": "bearer", "expires_in": 51...} görünür. Bu access_token değeri INSTAGRAM_ACCESS_TOKEN olacak.

4. Ortam ayarlarına ekle

Claude Code → Project settings → Ortam → Default yanındaki dişli. Ortam değişkenlerine ekle:

INSTAGRAM_USER_ID=17841430694540020
INSTAGRAM_ACCESS_TOKEN=3. adımdaki uzun token

İzinli alan adlarına graph.instagram.com ekle ve kaydet. Sonra bu sayfayı kapat.
